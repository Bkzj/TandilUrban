# Guía de seguridad de cuenta

Creá tu cuenta y verificá el correo recibido antes de ingresar. Si olvidás la contraseña, solicitá un enlace de recuperación desde la pantalla de acceso; nunca compartas ese enlace.

Cuando esté habilitada la seguridad de dos pasos, escaneá el QR con una aplicación autenticadora y guardá los códigos de respaldo en un lugar seguro. Cada código sirve una sola vez y no se puede recuperar después. Si perdés el dispositivo autenticador, usá un código de respaldo y configurá una nueva aplicación cuanto antes. Si no tenés códigos, contactá soporte por un canal verificado.
